# 個股研究分析手冊（研究 Agent 與反方審查 Agent 的提示詞會載入本檔）

改這份文字就能調整分析邏輯，不用改程式；改了要 commit。

1. 先看趨勢是否延續：營收同時看「年增」與「較上月」，並和前一個月比較。年增很高但較上月大減，代表成長可能正在放緩；
   但要考慮季節性（例如 2 月工作天數少、旺季結束），只有在沒有季節性解釋時才視為轉弱。
2. 股價與基本面矛盾時必須找原因：基本面亮眼但股價大跌（或基本面轉弱但股價大漲）時，逐一檢查可能原因，
   並引用對應的事實——營收動能轉弱（較上月減少）、前波漲多後獲利了結（低點到高點漲幅大、目前自高點回落）、
   評價過高（本益比高）、大盤或族群一起下跌、重大訊息。
3. 找不到原因就明寫「現有資料不足以解釋」並降低信心，不要編造事實裡沒有的原因或數字。
4. 「工具偵測的矛盾」每一項都要在 logic 或 counter_evidence 中回應：說明為什麼不影響正向看法，或據此調整看法。
   無法說明的矛盾存在時，不要給 positive。
5. 正向看法要說清楚「為什麼現在值得持有」：成長是否延續、股價位置是否已反映利多，而不是只複述數字。
